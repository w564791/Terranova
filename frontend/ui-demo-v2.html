变更说明

FIXBoolean 开关

问题：当前 FormField.tsx 中的 bool 开关是一个裸 <button>，无状态文字、无 accessible label、无 disabled 态、绿色 #10b981 与主色系不一致。SwitchWidget.tsx 依赖 Ant Design valuePropName="checked"，在嵌套 object/array 中易出现值注入失败。
修复：① 统一蓝色主色 #3b82f6；② 旁边附状态文字"已启用/未启用"，对色弱用户友好；③ 明确 disabled 态（opacity + cursor:default）；④ DynamicForm 和 OpenAPIFormRenderer 统一 Switch 行为。

NEWSource & Version

问题：当前 ViewResource 用 const { source, version, ...configData } 把这两个关键字段过滤掉了；EditResource 至少保留了 version 但也过滤了 source。用户无法感知资源的模块来源和版本。
方案：在表单顶部增加 Source/Version 信息卡片——等宽字体 + 浅灰底 + 分隔线，始终可见但不参与表单编辑。HCL 视图中也完整呈现。

NEWJSON → HCL

问题：当前数据视图显示 JSON.stringify(data, null, 2)，但用户实际操作的是 Terraform 资源，HCL 才是原生语言。
方案：实现 jsonToHCL() 转换函数，输出标准 Terraform HCL 格式。深色代码块（#1e293b）+ 语法高亮（关键字紫色、属性蓝色、字符串绿色、布尔红色、数字橙色）。支持嵌套 object、array、map 的缩进渲染。含复制按钮。

UIDescription 层级

description 12px + #9ca3af（gray-400），label 13.5px + #374151（gray-700）。通过色彩浓度差而非仅字号差拉开层级，description 轻盈但不突兀。

UI配色统一

全部统一到 Tailwind Slate/Gray 中性色 + #3b82f6 交互蓝。消除 Google Material #4285F4 与 Tailwind #3b82f6 的混用。Section header 用渐变浅底 + 小图标替代纯色灰底。

UI只读模式

去掉 filter: grayscale(30%) 全局灰化，改为精确设置 background + border + text color。Switch 用 opacity: 0.6 + cursor: default 表示不可操作，不会导致图片或图标失真。
