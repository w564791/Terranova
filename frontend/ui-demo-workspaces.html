现状主要问题 → 方案 A 对应改动

  • 套娃边框：页面再套一层带 inset 阴影的大卡片，视觉发闷
  • 垂直层级过多：Page header → Workspaces bar → Filters bar → Table header，连着 4 条分割线
  • 状态筛选难懂：只有图标 + 数字，没有文案
  • 项目侧栏信息少：无数量、搜索按钮形同虚设
  • 行信息扁平：无 tags、无快捷操作、状态 badge 偏方
  • 去掉外层重卡片：内容区直接铺在 bg 上，侧栏/主区各自轻边框
  • 合并顶栏：标题 + 统计副标题 + 主操作同一行
  • 状态变成可点卡片：Needs attention / Failed / Running / Healthy
  • 侧栏项目 + count：首字母块 + 数量 pill + 常驻搜索
  • 行信息分层：首字母 avatar、描述、tags、pill 状态、mode code、⋯ 菜单
